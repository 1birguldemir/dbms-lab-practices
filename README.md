# 🗄️ DBMS Lab Practices

A collection of Database Management Systems (DBMS) laboratory exercises and SQL scripts completed during coursework. 

### 📋 Project Overview
This repository contains a few select lab practices focused on foundational relational database concepts. These exercises demonstrate practical knowledge of database design, querying, and data manipulation.

### ✨ Topics Covered in Labs
* **Data Definition:** Creating and altering tables, defining keys.
* **Data Manipulation:** Inserting, updating, and modifying records.
* **Querying:** Writing fundamental SQL queries to extract and filter data.

### 🛠️ Tech Stack
* **Language:** SQL

### 🚀 About
These scripts serve as practical examples of academic coursework, showcasing a solid understanding of core database management principles.
